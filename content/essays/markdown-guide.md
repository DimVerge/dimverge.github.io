{{< epigraph >}}写下的文字，也需要自己的排版。这里用一篇小说明，列出微隅支持的所有写法，每条都附上代码样例。{{< /epigraph >}}

## 段落与引言

正文段落会自动首行缩进两字；写在开头的引言会空两格显示，前面加破折号，用衬线字体与正文区分。

```
> 有些夏天，结束以后，就再也没有回来。
```

## 小标题

用 ## 表示分节标题，用 ### 表示更小的分节。

```
## 我们曾经站在夏天里
### 更小的分节
```

## 加粗、斜体与行内代码

可以给词句加上 **重点**，也可以用 *斜体* 写一句英文，比如 *quietly.*；提到某个写法时，可以用 `# 标题` 这样的行内代码。

```
可以给词句加上 **重点**，也可以写 *quietly.*
提到底层写法时，可以用 `# 标题` 这样的行内代码。
```

## 引文

想摘录或强调某句话时，用引用块：

```
> 有些告别没有声音，却在某一天突然完成。
```

## 列表

```
- 随笔：正文段首缩进两字，引言空两格加破折号
- 连载：按小说分组，章内顺序阅读
- 引文：缩进显示，左侧细线

1. 写下文字
2. 选择排版
3. 慢慢发布
```

## 分隔线

想在两个小节之间停顿一下，可以用一条分隔线：

```
---
```
