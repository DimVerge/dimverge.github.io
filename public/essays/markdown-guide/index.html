Markdown 排版说明

a short guide to markdown
微隅正文支持的写法一览
写下的文字，也需要自己的排版。这里用一篇小说明，列出微隅支持的所有写法，每条都附上渲染效果与代码样例。

段落与引言

正文段落会自动首行缩进两字；写在开头的引言会空两格显示，前面加破折号，用衬线字体与正文区分。

上面这段就是普通段落的渲染效果；下面这行是引言：

有些夏天，结束以后，就再也没有回来。

写法：

> 有些夏天，结束以后，就再也没有回来。

小标题

用 ## 表示分节标题，用 ### 表示更小的分节。渲染效果就是本文各小节的标题本身，例如：

我们曾经站在夏天里

更小的分节

写法：

## 我们曾经站在夏天里
### 更小的分节

加粗、斜体与行内代码

可以给词句加上 重点，也可以用 斜体 写一句英文，比如 quietly.；提到某个写法时，可以用 # 标题 这样的行内代码。上面这句本身就展示了三种效果。

写法：

可以给词句加上 **重点**，也可以写 *quietly.*
提到底层写法时，可以用 `# 标题` 这样的行内代码。

引文

想摘录或强调某句话时，用引用块。渲染效果：

有些告别没有声音，却在某一天突然完成。

写法：

> 有些告别没有声音，却在某一天突然完成。

列表

无序列表与有序列表都可以用，条目多时尤其合适。渲染效果：

  • 随笔：正文段首缩进两字，引言空两格加破折号
  • 连载：按小说分组，章内顺序阅读
  • 引文：缩进显示，左侧细线
  1. 写下文字
  2. 选择排版
  3. 慢慢发布

写法：

- 随笔：正文段首缩进两字，引言空两格加破折号
- 连载：按小说分组，章内顺序阅读
- 引文：缩进显示，左侧细线

1. 写下文字
2. 选择排版
3. 慢慢发布

任务清单

想记录未竟之事，可以用任务清单，勾选状态会直接显示。渲染效果：

  • 写完这一篇
  • 校一遍错字
  • 挑一个安静的下午发布

写法：

- [x] 写完这一篇
- [ ] 校一遍错字
- [ ] 挑一个安静的下午发布

链接

给文字加上去处。渲染效果：

微隅的档案

写法：

[微隅的档案](https://dimverge.github.io/)

图片

插图用图片语法，方括号里写的是无法显示时的说明。渲染效果（站内现用图标）：

写法：

![微隅站标](/favicon.svg)

表格

需要对照的信息可以用表格，冒号控制对齐。渲染效果：

季节 月份 光线
春 三—五月 明亮
秋 九—十一月 柔和

写法：

| 季节 | 月份 | 光线 |
| :--- | :---: | ---: |
| 春 | 三—五月 | 明亮 |
| 秋 | 九—十一月 | 柔和 |

删除线

写错或作废的话，可以划掉而不是删掉。渲染效果：

这句话已经作废

写法：

~~这句话已经作废~~

代码块与语言标注

独立成块的代码用三个反引号包裹，可以标注语言；行内代码只用一个反引号。渲染效果：

print("quietly")

写法（三个反引号包裹，开头标注语言）：

```python
print("quietly")
```

脚注

需要补一句注脚时，用脚注语法，注释会收在文末。渲染效果：

这是正文里的句子，带着一个注脚1。

写法：

这是正文里的句子[^1]。

[^1]: 注脚的内容，写在文末。

分隔线

想在两个小节之间停顿一下，可以用一条分隔线。渲染效果：

写法：

---

转义

偶尔需要让符号按字面显示，用反斜杠转义。渲染效果：

* 不是强调的开始。

写法：

\* 不是强调的开始。

以上就是全部写法，祝写作愉快。

  1. 注脚的内容，写在文末。 ↩︎
